A. Etiquetas de estructura básica

Este grupo de etiquetas no se ve directamente en la página, pero sostiene toda la página revisa el código fuente para comprobarlas.

  • <html lang="es">: elemento raíz, define el idioma de la página.
  • <head>: agrupa <title>, <meta>, <link> y <base>.
  • <title>: mira la pestaña de tu navegador — dice "Tarea 1 - Etiquetas HTML5 - Emanuel".

  • <link rel="stylesheet">: aplica el color de fondo y la tipografía que ves (viene de style.css).
  • <meta charset="UTF-8">: permite que tildes y "ñ" se vean bien:áéíóú ñ.
